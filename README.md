# 🔍Custom Search Engine

A Python-based CLI search engine powered by the Exa API that fetches and displays real-time, keyword-based web search results with domain-specific filtering.

---

## 📌Overview

This project demonstrates how to build a functional search engine from scratch using an external search API. It accepts user queries via the command line and returns structured web results including titles and URLs.

---

## ✨Features

- 🔎 Real-time keyword-based web search using Exa API
- 🌐 Domain-specific filtering for targeted results
- 🖥️ Clean CLI interface for seamless user interaction
- 📋 Structured result display with titles and URLs
- ⚡ Returns top 5 most relevant results per query

## 🚀How to Run

1. Clone the repository:
```bash
git clone https://github.com/gunn0067/custom-search-engine.git
```

2. Install dependencies:
```bash
pip install exa-py
```

3. Run the search engine:
```bash
python main.py
```

4. Enter your search query when prompted:
```
Search here: latest AI developments
```
